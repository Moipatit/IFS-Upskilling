Travel Planning Website

Application Overview

The application that I selected is a Travel planning platform. This platform is aimed at people who you are planning to travel in the near future. Traveling can be very stressful because it requires a lot of planning. The purpose of this application is have a single platform to handle all of the planning and to help reduce the stress that occurs with organizing a trip.

Traditional Feature

One traditional feature of a travel planning website would be a standard travel itinerary. Travel planning websites usually rely on specialized travel software to create their itineraries. Planners pull pre-configured information such hotels, guided tours and seasonal pricing from a centralized database.

Generative AI feature

I would redesign the feature by personalizing the itinerary for the user. The user would input the following information:

  • Destination
  • Travel goal (e.g relaxation, food, exploration, adventure)
  • The length of the trip (e.g 7 days, 2 weeks, 1 Month)
  • Number of people
  • Budget
  • Preferred pace (relaxed vs fast-paced)

The application would create a customized day-to-day built around all of the information that the user shared. This generated output creates a more personalized experience because it is tailored to the user's needs. This approach gives more value because instead of the user being given generic information they have a itinerary that is custom made for them.
