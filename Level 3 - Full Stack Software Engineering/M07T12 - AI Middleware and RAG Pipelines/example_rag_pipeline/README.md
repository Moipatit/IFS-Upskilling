# Example RAG Pipeline

This example project demonstrates how a simplified Retrieval-Augmented Generation pipeline works.

It does not use a real AI API. Instead, it uses local JavaScript files to show each stage of the pipeline clearly.

## What this example teaches

This project demonstrates how to:

1. Load a local knowledge base.
2. Divide information into smaller chunks.
3. Retrieve relevant chunks based on a user's question.
4. Build an augmented prompt.
5. Simulate an AI-generated response.
6. Display each stage in the browser.
