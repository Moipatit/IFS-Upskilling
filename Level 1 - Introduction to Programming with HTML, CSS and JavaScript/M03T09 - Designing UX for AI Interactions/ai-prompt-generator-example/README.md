# AI Prompt Generator Example

This folder contains a simple front-end example for Task 25: Designing UX for AI Interactions.

## Files

- `index.html` contains the page structure.
- `style.css` contains the styling.
- `script.js` contains the loading state, retry behavior, and user feedback logic.

## How to use this example

Open `index.html` in your browser and inspect how the interface is structured.

The API endpoint in `script.js` is a placeholder:

https://api.example.com/generate

In a real project, this URL must be replaced with the AI API endpoint provided for the assignment.
